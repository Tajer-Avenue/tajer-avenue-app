# Tajer Avenue

Tajer Avenue is a UAE-focused multi-vendor marketplace for product businesses, service businesses, suppliers, sellers, and buyers.

## Product vision

A modern digital mall where every merchant gets a customizable storefront while customers can discover, shop, book services, and connect with businesses across the UAE.

## Current customer foundation

- Modular Flutter structure with centralized temporary branding
- Working Home, Explore, Saved, Stores, Store preview, and Account navigation
- Local search and favorites state using mock catalog data
- Empty shared-cart entry point ready for the checkout domain
- Responsive Material 3 interface for mobile and web

## Next delivery milestone

- Supabase project environments and typed data layer
- Authentication and customer profiles
- Merchant onboarding and automatic storefront creation
- Product/service details and shared cart
- Orders, checkout, and payment-provider integration

## Planned merchant experience

- Seller dashboard
- My Store
- Store customization (logo, cover, colors, video, links, and theme)
- Products and services
- Orders
- Analytics
- Subscription

## Stack

- Flutter
